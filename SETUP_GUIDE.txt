# NSE NIFTY 50 Algorithmic Trading System - Project Summary

## 📊 Project Overview

A complete, production-ready algorithmic trading system for the NSE NIFTY 50 index with advanced technical analysis, risk management, and comprehensive backtesting capabilities.

## 📁 Project Structure

```
3ed/
├── algo_trader.py          # Main trading engine (850+ lines)
├── config.py               # Configuration parameters
├── utils.py                # Utility functions and helpers
├── examples.py             # Usage examples
├── quickstart.py           # Interactive quick start guide
├── requirements.txt        # Python dependencies
├── README.md               # Full documentation
└── SETUP_GUIDE.txt         # This file
```

## 🚀 Quick Start (3 Steps)

### Step 1: Install Dependencies
```bash
cd "3ed"
pip install -r requirements.txt
```

### Step 2: Run Quick Start
```bash
python quickstart.py
```

### Step 3: Run Your First Backtest
```python
from algo_trader import AlgoTrader
from datetime import datetime, timedelta

trader = AlgoTrader(initial_capital=100000)
end_date = datetime.now().strftime('%Y-%m-%d')
start_date = (datetime.now() - timedelta(days=365)).strftime('%Y-%m-%d')
report = trader.backtest(start_date, end_date)
trader.print_report(report)
```

## 🎯 Key Features

### 1. Advanced Strategy
- **SMA Crossover**: Fast (20) and Slow (50) moving averages
- **RSI Indicator**: Overbought (70) and oversold (30) levels
- **MACD**: Momentum confirmation
- **Multi-indicator confirmation**: All signals must align

### 2. Risk Management
- **Position Sizing**: Based on risk/reward ratio
- **Stop-Loss Orders**: 2% below entry price
- **Maximum Drawdown**: 10% limit
- **Capital Allocation**: Max 5% per position
- **Risk Per Trade**: 2% of capital

### 3. Backtesting Engine
- **Historical Data**: Yahoo Finance (yfinance)
- **Detailed Trade Analysis**: Entry/exit prices, durations, P&L
- **Performance Metrics**: Win rate, profit factor, Sharpe ratio
- **Trade Logging**: CSV and JSON export

### 4. Analysis Tools
- **Technical Indicators**: SMA, EMA, RSI, MACD, Bollinger Bands, ATR
- **Performance Analyzer**: Comprehensive metrics calculation
- **Strategy Optimizer**: Parameter sweep and optimization
- **Data Validator**: Data quality checks
- **Report Generator**: HTML and JSON reports

## 📈 Core Components

### AlgoTrader (Main Class)
- `fetch_data()`: Download NIFTY 50 data from Yahoo Finance
- `backtest()`: Run historical backtest with signal generation
- `generate_backtest_report()`: Calculate performance metrics
- `print_report()`: Display results

### TradingStrategy
- `generate_signals()`: Multi-indicator signal generation
- Customizable parameters for strategy tuning

### RiskManager
- `calculate_position_size()`: Optimal position sizing
- `check_drawdown_limit()`: Drawdown monitoring
- `update_capital()`: Capital tracking

### TechnicalIndicators
Static methods for:
- SMA, EMA
- RSI
- MACD
- Bollinger Bands
- ATR

## 💻 Usage Examples

### Basic Backtest
```python
from algo_trader import AlgoTrader
from datetime import datetime, timedelta

trader = AlgoTrader(initial_capital=100000)
end_date = '2024-01-15'
start_date = '2022-01-15'
report = trader.backtest(start_date, end_date)
trader.print_report(report)
```

### Custom Strategy Parameters
```python
from algo_trader import AlgoTrader, TradingStrategy

trader = AlgoTrader(initial_capital=100000)
trader.strategy = TradingStrategy(
    fast_sma=10,
    slow_sma=30,
    rsi_period=10
)
report = trader.backtest(start_date, end_date)
```

### Fetch and Analyze Data
```python
from algo_trader import AlgoTrader

trader = AlgoTrader()
df = trader.fetch_data('2023-01-01', '2024-01-15')
print(df.tail())
print(f"Total candles: {len(df)}")
```

### Parameter Optimization
```python
from utils import StrategyOptimizer
from algo_trader import AlgoTrader

trader = AlgoTrader()
results = StrategyOptimizer.parameter_sweep(
    trader,
    fast_sma_range=[10, 15, 20],
    slow_sma_range=[30, 50, 70],
    start_date='2023-01-01',
    end_date='2024-01-15'
)
print(results.nlargest(5, 'return_percent'))
```

## 📊 Output Metrics

### Backtest Report Includes:
- **Total Trades**: Number of completed trades
- **Win Rate**: % of profitable trades
- **Winning/Losing Trades**: Count breakdown
- **Total P&L**: Absolute profit/loss in rupees
- **Total Return**: Return percentage on capital
- **Average Win/Loss**: Mean trade size
- **Profit Factor**: Total profit / Total loss ratio
- **Max Drawdown**: Largest peak-to-trough decline
- **Trade Details**: Entry/exit prices, dates, P&L per trade

## 🛠️ Troubleshooting

### Import Error
```bash
pip install pandas numpy yfinance python-dateutil
```

### No Data Downloaded
- Check internet connection
- Verify symbol (^NSEI for NIFTY 50)
- Check date range validity

### Strategy Not Generating Signals
- Verify data has sufficient candles (>50)
- Check indicator periods are smaller than data length
- Review strategy logic in config
